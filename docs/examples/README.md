# Design examples

These files show the **target schemas** described in the
[implementation blueprint](../IMPLEMENTATION-BLUEPRINT.md). They are design
examples, not configuration that the current build validates yet.

- `zentrion.toml` — full terminal configuration
- `workspace.yaml` — tabs, panes, layouts and restore policy
- `workflow.yaml` — parameterized workflow with an approval step
- `agents/claude-code.yaml` — agent adapter manifest
- `policy.yaml` — extended policy with agent profiles and network rules
