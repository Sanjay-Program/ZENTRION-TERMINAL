# Local Storage

Zentrion stores user data outside the application binary and installer
directories. Normal upgrades, binary replacement and uninstall preserve this
data.

## Inspect Storage

```sh
z storage show
z storage doctor
z storage policy
z setup
```

`z setup` creates missing storage directories and writes a `storage.json`
manifest under the user data directory.

## Retention Contract

| Data | Survives upgrade | Survives binary delete | Removed by normal uninstall |
|---|---:|---:|---:|
| Configuration | yes | yes | no |
| Audit log | yes | yes | no |
| Installed tools | yes | yes | no |
| Sessions/history | yes | yes | no |
| Agent/project memory | yes | yes | no |
| Scan reports | yes | yes | no |
| Cache | yes, but disposable | yes, but disposable | no |

Cache can be cleaned because verified artifacts can be reacquired or rebuilt.
Configuration, audit, tools, sessions, memory and reports are durable user data.

## Platform Paths

| Platform | Config | Data | Cache |
|---|---|---|---|
| Linux | `$XDG_CONFIG_HOME/zentrion` or `~/.config/zentrion` | `$XDG_DATA_HOME/zentrion` or `~/.local/share/zentrion` | `$XDG_CACHE_HOME/zentrion` or `~/.cache/zentrion` |
| macOS | `~/Library/Application Support/Zentrion` | `~/Library/Application Support/Zentrion` | `~/Library/Caches/Zentrion` |
| Windows | `%APPDATA%\Zentrion` | `%LOCALAPPDATA%\Zentrion` | `%LOCALAPPDATA%\Zentrion\Cache` |

Overrides:

```sh
ZENTRION_CONFIG_DIR=/path/to/config
ZENTRION_DATA_DIR=/path/to/data
ZENTRION_CACHE_DIR=/path/to/cache
```

## What Installers May Remove

Installers and uninstallers may remove:

- the `z` executable,
- bundled application docs copied into the install prefix,
- desktop/start-menu integration generated by the installer.

They must not silently remove user data. Any future destructive purge command
must require explicit user confirmation and should show the exact directories
before deletion.
