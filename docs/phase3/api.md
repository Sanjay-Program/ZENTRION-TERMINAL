# API

The core Phase 3 APIs are:

- `Engine`
- `EngineRequest`
- `EngineResult`
- `EngineRegistry`
- `Asset`
- `Finding`
- `ScanProfile`
- `ScanReport`
- `ScanOrchestrator`

The first CLI surfaces are:

- `z engine list`
- `z engine info <name>`
- `z engine doctor`
- `z scan [--profile NAME] <target>`
- `z finding list`
- `z report latest`
- `z asset list`
- `z sbom`
- `z ai analyze`
